# Güvenlik bildirimi

Bu proje erken geliştirme aşamasındadır ve günlük kullanım için hazır değildir.

Güvenlik açığı olduğunu düşündüğünüz bir durumu herkese açık issue veya Discussions gönderisine koymadan önce GitHub repo sayfasındaki Security → Report a vulnerability seçeneğini kontrol edin. Bu seçenek etkin değilse, bakım ekibiyle iletişim kurmak için repo ana sayfasındaki iletişim bilgisini kullanın. Parola, anahtar veya özel kullanıcı verisi paylaşmayın.
